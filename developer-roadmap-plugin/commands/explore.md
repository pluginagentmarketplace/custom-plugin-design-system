# Explore Developer Roadmaps

Explore all 66+ developer career paths and roadmaps available in the Developer Roadmap project.

## Description

This command helps you discover and understand all available developer roadmaps across different specializations and career paths.

## Usage

```
/explore [category]
```

## What You'll Learn

Each roadmap includes:
- **Prerequisites**: What to know before starting
- **Core Skills**: Essential knowledge and tools
- **Specializations**: Advanced topics and areas
- **Learning Resources**: Courses, documentation, tutorials
- **Practice Projects**: Hands-on learning opportunities
- **Time Estimates**: How long to master each topic

## Next Steps

After exploring:
1. Choose a roadmap that interests you
2. Use `/path` to create personalized learning
3. Use `/assess` to evaluate your current skills
4. Ask agents for detailed guidance
