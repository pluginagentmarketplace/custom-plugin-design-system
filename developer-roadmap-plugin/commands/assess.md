# Assess Your Skills

Get a comprehensive assessment of your current technical skills and identify knowledge gaps.

## Description

This command helps you evaluate your expertise across different technical areas using official Developer Roadmap knowledge assessments.

## Usage

```
/assess [area]
```

## Available Assessments

### Core Language Assessments
- **JavaScript** - Core JavaScript knowledge and ES6+
- **TypeScript** - Type systems and advanced features
- **Python** - Python fundamentals and ecosystem

### Framework Assessments
- **React** - Component patterns, hooks, state management
- **Vue** - Vue composition API, reactivity, components
- **Angular** - Dependency injection, RxJS, templates

### Backend Assessments
- **Node.js** - Runtime, module system, async patterns
- **Backend** - Database, APIs, architecture
- **Databases** - SQL, NoSQL, design patterns

### Frontend Assessments
- **Frontend** - HTML, CSS, JavaScript, web APIs
- **CSS** - Layout, flexbox, grid, animations
- **Accessibility** - A11y standards, WCAG guidelines

## Assessment Types

### Knowledge Assessment
- Multiple choice questions
- Code completion
- True/false statements
- Time limit: 30-60 minutes

### Practical Assessment
- Build a small feature
- Debug code problems
- Design an interface
- Time: 1-2 hours

### System Design Assessment
- Architecture questions
- Scalability scenarios
- Tradeoff analysis
- Time: 1-2 hours

## How It Works

1. **Take Assessment**
   - Answer questions based on your knowledge
   - No right or wrong answer (self-assessment)
   - Honest feedback gives best results

2. **Get Results**
   - Overall score and areas
   - Confidence by topic
   - Specific gap identification

3. **Review Gaps**
   - See topics with lowest scores
   - Get resource recommendations
   - Plan improvement areas

## Next Steps After Assessment

1. **Review Results**
   - Identify 2-3 key gaps
   - Note strong areas to build on

2. **Create Learning Plan**
   - Use `/path` to create personalized path
   - Focus on weakest areas first
   - Build on strengths

3. **Practice**
   - Complete projects using assessed skills
   - Retake assessments after 1-2 months
   - Track improvement over time

4. **Get Help**
   - Ask relevant agent for guidance
   - Deep dive into specific topics
   - Access skill guides and resources

## Retaking Assessments

- Retake anytime (recommended every 1-3 months)
- Track score improvements
- Celebrate progress
- Stay motivated with visible growth
