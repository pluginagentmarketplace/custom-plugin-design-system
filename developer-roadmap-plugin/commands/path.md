# Create Personalized Learning Path

Generate a customized learning journey based on your goals, current skills, and time availability.

## Description

This command creates a personalized learning path tailored to your specific situation, helping you efficiently reach your career goals.

## Usage

```
/path
```

Interactive questions will guide you through creating your perfect learning path.

## Assessment Questions

The command will ask about:

### Current Situation
- **Experience Level**: Beginner, intermediate, advanced
- **Current Skills**: What you already know
- **Background**: Education, prior experience
- **Time Available**: Hours per week you can commit

### Goal Definition
- **Target Role**: Where you want to be
- **Timeline**: 3 months, 6 months, 1 year
- **Motivation**: Career change, advancement, interest
- **Focus Areas**: Specific technologies or domains

### Learning Preferences
- **Learning Style**: Video, interactive, reading, hands-on
- **Budget**: Free vs paid resources
- **Community**: Solo learning vs group support
- **Intensity**: Fast-paced vs gradual

### Constraints
- **Work Schedule**: Full-time, part-time, other commitments
- **Previous Attempts**: What worked/didn't work
- **Challenges**: Areas that are difficult
- **Preferred Resources**: Favorite platforms/authors

## Tips for Success

- **Consistency > Intensity**: 10 hours/week regularly beats sporadic marathons
- **Project First**: Build things first, learn theory as needed
- **Share & Teach**: Explain what you learn to solidify understanding
- **Find Community**: Join groups working on similar paths
- **Celebrate Progress**: Acknowledge every milestone
- **Adjust Regularly**: Your path can evolve as you learn

## Frequently Asked Questions

**Q: How often should I retake the path assessment?**
A: Quarterly (every 3 months) or when major life changes occur

**Q: Can I combine multiple paths?**
A: Yes! The system suggests path combinations for roles

**Q: What if I can't follow the timeline?**
A: Adjust it! The path is flexible and should fit your life

**Q: How do I know if I'm on track?**
A: Use checkpoints and assessments to validate progress
