# Get Detailed Roadmap

View comprehensive, interactive roadmap for any specific developer career path.

## Description

This command provides a detailed breakdown of any developer role, including prerequisites, learning sequence, tools, best practices, and resources.

## Usage

```
/roadmap [role-name]
```

## Roadmap Sections

Each roadmap includes:

### 1. Overview
- Role description and responsibilities
- Average salary and job market
- In-demand skills and technologies
- Learning time estimate

### 2. Prerequisites
- Foundational knowledge needed
- Required experience level
- Soft skills important for role
- Preparation steps

### 3. Learning Path
- Organized by difficulty
- Sequential skill progression
- Time estimates for each section
- Recommended learning order

### 4. Core Technologies
- Essential tools and frameworks
- Languages and platforms
- Libraries and tools
- Version and compatibility info

### 5. Advanced Topics
- Specialization options
- Performance optimization
- Security best practices
- Architecture patterns

### 6. Projects & Practice
- Beginner projects
- Intermediate projects
- Advanced capstone projects
- Real-world scenarios

### 7. Resources
- Official documentation
- Online courses (free and paid)
- Books and blogs
- YouTube channels
- Communities and forums

### 8. Certifications
- Recommended certifications
- Optional credentials
- Exam preparation
- Value in job market

### 9. Career Progression
- Junior role responsibilities
- Senior role expectations
- Leadership opportunities
- Specialization paths

## Using Your Roadmap

### Week 1: Assessment
- Take `/assess` for your target role
- Identify current skill level
- Note knowledge gaps

### Week 2-4: Plan
- Use this roadmap to understand scope
- Create detailed learning schedule
- Choose learning resources

### Months 2+: Learn & Build
- Follow roadmap sequence
- Complete practice projects
- Build real applications

### Ongoing: Assess & Improve
- Retake assessments monthly
- Update learning plan
- Track progress
