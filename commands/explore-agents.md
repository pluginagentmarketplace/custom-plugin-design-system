## How to Use Agents

### Direct Agent Invocation

Each agent can be invoked with specific queries:

```
"@frontend-specialist: How do I build a responsive React app?"
"@backend-specialist: Explain JWT authentication in Node.js"
"@infrastructure-specialist: What's the difference between Docker and Kubernetes?"
"@data-specialist: How do I prepare data for machine learning?"
"@mobile-specialist: Should I learn React Native or Flutter?"
"@architecture-specialist: Design a URL shortening service"
"@database-specialist: How do I optimize PostgreSQL queries?"
```

### Parallel Learning

Learn from multiple agents simultaneously:

```
/explore-agents --parallel

This allows you to:
- Compare approaches across specialties
- Learn connections between domains
- Understand full-stack implications
- Build comprehensive knowledge
```

## Getting Started

1. **Explore by agent**: `/explore-agents frontend`
2. **See agent capabilities**: `@agent-name capabilities`
3. **Get agent recommendations**: `@agent-name recommend [topic]`
4. **View learning paths**: `/explore-agents --paths`
5. **Find projects**: `/projects --agent [name]`
