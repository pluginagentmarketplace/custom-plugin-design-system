# /learn - Start Your Learning Journey

Welcome to the Developer Roadmap Learning System! This command helps you choose a personalized learning path and get started with the roadmap that matches your goals.

## What This Does

When you use `/learn`, you'll:

1. **Choose your focus area** - Select from 7 specialization domains:
   - Frontend Development
   - Backend Development
   - Infrastructure & DevOps
   - Data Science & AI
   - Mobile & Game Development
   - Software Architecture
   - Database & Security

2. **Select your experience level**:
   - Beginner (0-6 months experience)
   - Intermediate (6-18 months experience)
   - Advanced (18+ months experience)

3. **Get a personalized roadmap** with:
   - Learning path duration
   - Key skills to master
   - Recommended projects
   - Resource links

## Tips for Success

1. **Consistent Learning** - Dedicate 2-3 hours per day
2. **Hands-On Practice** - Build projects alongside learning
3. **Review Progress** - Use `/assess` to track advancement
4. **Ask Questions** - Leverage Claude for explanations
5. **Join Community** - Connect with other learners

## Advanced Options

- `--fast`: Accelerated path (higher intensity)
- `--slow`: Extended path (slower pace)
- `--focus={skill}`: Focus on specific skill
- `--projects`: Project-heavy path

Example: `/learn --fast --focus=react`
